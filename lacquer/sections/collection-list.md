# Collection list

A grid of collection tiles. Each tile renders a collection image, name, and a link to the collection page.

## What it does

Pulls a list of collections (manually selected via collection blocks) and renders them as a tile grid. Configurable column count and tile composition.

## Section settings

Documentation in progress. Key settings: columns desktop (2–6), columns mobile (1 or 2), enable carousel on mobile, padding, color scheme.

## Blocks

- **Collection** — Collection picker, optional override image, optional override name.

## Example use cases

- **Category routing** — Three collection tiles routing to Decks, Apparel, Hard goods. Used directly below the homepage hero.
- **Drop archive** — Six collection tiles routing to past drops by edition number.
- **Editorial split** — Four collection tiles routing to themed collections (Spring drop, Fall drop, Collaborations, Stock).

## Notes

Use collection-list (not featured-collection) when you want to route to collections, not surface products. The two sections serve different intents.
