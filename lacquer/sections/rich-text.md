# Rich text

A centered or aligned column section with heading and body text. The lightest-weight content section — used wherever a page wants a written interlude between heavier sections.

## What it does

Renders a column of text content. Heading, subheading, body, and button blocks compose into a readable column. Configurable column width and content alignment.

## Section settings

Documentation in progress. Key settings: width (small / medium / large / full), content alignment (left / center / right), padding, color scheme.

## Blocks

- **Heading** — Section headline.
- **Subheading** — Small heading.
- **Text** — Body copy.
- **Button** — Optional call-to-action.
- **Caption** — Small caption text.

## Example use cases

- **Mission statement** — Short heading plus a paragraph of body, centered, narrow column.
- **Section divider** — Just a heading block, left-aligned, used to break a long page into named sections.
- **Call-to-action** — Heading, short text, button. Centered, narrow column. Used as a closer below a content block.

## Notes

The rich-text section is the right choice when you want text without image weight. For text-with-image, use [Image with text](./image-with-text) instead.
