# Video

Renders a hosted (YouTube, Vimeo) or Shopify-uploaded video. Optional poster image, optional overlay heading and text, autoplay and loop configuration.

## What it does

Embeds video into a section. Supports both Shopify-hosted media (uploaded via Settings → Files) and external embed URLs (YouTube, Vimeo). Renders with an optional poster frame and overlay content.

## Section settings

Documentation in progress. Key settings: video source (Shopify upload or URL), poster image, autoplay, loop, mute, show controls, padding, color scheme.

## Blocks

- **Heading** — Optional overlay heading.
- **Text** — Optional overlay text.
- **Button** — Optional overlay button.

## Example use cases

- **Studio video** — Looped, muted, autoplay video of the studio or product in use. Used as an atmospheric homepage section.
- **Product demonstration** — A click-to-play video on a product landing page showing the product in context.
- **Drop trailer** — A short trailer for an upcoming drop, used on the homepage with a button overlay routing to the drop's collection.

## Notes

Autoplay requires the video to be muted. Browsers block autoplay with sound. For autoplay-with-sound, the visitor must initiate playback.
