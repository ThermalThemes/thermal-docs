# Testimonials

Quote blocks with attribution. Used for press quotes, customer reviews, retailer endorsements, or community voices.

## What it does

Renders a section of quote blocks. Each quote carries the quote text, attribution, and optional source link or avatar image.

## Section settings

Documentation in progress. Key settings: layout (single column, carousel, grid), columns desktop, enable carousel on mobile, padding, color scheme.

## Blocks

- **Quote** — Quote text, attribution name, attribution role, optional avatar, optional source link.

## Example use cases

- **Press strip** — Three quotes from press pieces, each linked to the source. Used as a homepage trust strip.
- **Customer voices** — Six quotes from past customers, used on the about page or below the footer.
- **Retailer endorsements** — For wholesale-routed brands, quotes from stockists.

## Notes

Don't manufacture quotes. Real attribution carries weight; invented quotes are immediately legible to readers.
