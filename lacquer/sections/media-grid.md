# Media grid

An asymmetric grid of images and video blocks. Editorial register — used for studio galleries, drop documentation, process spreads, and behind-the-scenes content.

## What it does

Renders an asymmetric grid where blocks can take 1, 2, or 3 columns. Used to break the regular grid rhythm of the rest of the homepage with an editorial spread.

## Section settings

Documentation in progress. Key settings: column count, row gap, padding, color scheme.

## Blocks

- **Image** — Image, optional caption, optional link, column span (1 / 2 / 3).
- **Video** — Video URL or upload, optional poster image, column span.

## Example use cases

- **Drop documentation** — Six images from the latest drop's shoot, varied column spans.
- **Studio gallery** — Photos of the studio, workspace, samples — used as an about-page section.
- **Process spread** — Process photography that spans the page, like an editorial magazine layout.

## Notes

Media grid is heavy on render. Use sparingly; one per page is usually right. The section is intentionally asymmetric — symmetric grids should use [Multi-column](./multi-column) instead.
