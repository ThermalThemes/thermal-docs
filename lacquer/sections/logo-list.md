# Logo list

A row of brand logos. Used for press logos ("As seen in"), stockists, brand partners, or certifications.

## What it does

Renders a row of logo images. Configurable column count, image size, optional logo links, optional carousel on mobile.

## Section settings

Documentation in progress. Key settings: heading, logo size, columns desktop (3–8), enable carousel on mobile, padding, color scheme.

## Blocks

- **Logo** — Logo image, optional link.

## Example use cases

- **Press strip** — "As seen in" plus logos for outlets that covered the brand.
- **Stockist row** — "Available at" plus retailer logos.
- **Certification row** — "Made with" plus material or method certifications.

## Notes

Logos work best as monochrome marks on a single color scheme. Multi-color logos in a row read as noise unless the row is intentionally a brand showcase.
