# Recently viewed

A grid of products the current visitor has recently viewed. Stored in browser local storage; persists across sessions until cleared.

## What it does

Renders a grid of recently viewed products for the current visitor. Hidden when the visitor has no viewing history. Used on product pages, collection pages, and cart pages.

## Section settings

Documentation in progress. Key settings: heading, products to show, columns desktop, columns mobile, enable carousel on mobile, padding, color scheme.

## Blocks

- **Heading** — Section headline.
- **Subheading** — Small heading.

## Example use cases

- **Product page "Recently viewed"** — Used directly below product recommendations.
- **Collection page** — Used at the bottom of the collection grid to help returning visitors find products they considered.
- **Cart page** — Used to remind visitors of products they viewed but didn't add to cart.

## Notes

Recently viewed is empty for first-visit visitors. The section auto-hides when there's no history, so it can be safely added anywhere without leaving an empty container on first visit.
