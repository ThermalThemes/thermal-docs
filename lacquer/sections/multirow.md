# Multirow

Stacked rows of image-and-text content. Each row is an alternating image-and-content layout. Used for editorial composition — product stories, process narratives, founder profiles.

## What it does

Renders multiple alternating image-and-text rows in a single section. Configurable per-row image position, image aspect, and content alignment.

## Section settings

Documentation in progress. Key settings: image aspect ratio, row spacing, alternating layout (auto-flip image position per row), padding, color scheme.

## Blocks

- **Row** — Image, heading, text, button, image position override.

## Example use cases

- **Product story** — Three rows telling the story of a single product: process, materials, finishing. Each row image left, content right; alternation visually clear.
- **Founder profile** — Four rows: studio image and bio, process image and method, location image and city context, product image and current drop.
- **Collection story** — Two rows: drop overview, then production credit.

## Notes

Multirow replaces stacks of image-with-text sections when you want consistent rhythm across rows. Use multirow when the content is one narrative; use stacked image-with-text when the rows are independent.
