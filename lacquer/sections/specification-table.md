# Specification table

A spec table for product detail. Used to render structured product specifications — dimensions, materials, edition info, technical data — in a consistent table format.

## What it does

Renders a section with one or more spec tables. Each table has a heading and rows of label-value pairs. Supports both categorical specs (string values) and numeric specs (with optional units).

## Section settings

Documentation in progress. Key settings: heading, table layout (single column or two-column), show borders, padding, color scheme.

## Blocks

- **Spec row** — Label, value, optional unit suffix.
- **Section heading** — Sub-heading inside the table to group related rows.

## Example use cases

- **Deck specs** — 7-ply Canadian maple, 8.0″ width, 14.25″ wheelbase, 31.75″ length, medium concave, edition of 150.
- **Apparel specs** — 7oz cotton, garment-dyed, cut and sewn in Porto, three colorways.
- **Material specs** — Used on a process page to detail materials used across the catalog.

## Notes

Specification tables read best on product pages, embedded directly below the product description. For homepage or landing-page use, consider whether the spec depth is appropriate to the context.
