# Image with text

A split-layout section. Image on one side, content (heading, text, button) on the other. The workhorse section for editorial homepage composition and informational page content.

## What it does

Renders a two-column layout — image left or right, content opposite. Configurable image position, width, aspect ratio, and mobile behavior. Supports alternating layout via multiple section instances.

## Section settings

Documentation in progress. Key settings: image, image position (left or right), image width, image aspect ratio, mobile image position, content vertical alignment, padding, color scheme.

## Blocks

- **Heading** — Section headline.
- **Subheading** — Small heading above the main heading.
- **Text** — Body copy.
- **Button** — Optional call-to-action.
- **Caption** — Small caption text, often used for credit or context.

## Example use cases

- **Founder note.** Image of the studio or founder, text block with a few sentences of context. Image left, content right.
- **Process detail.** Photograph of the manufacturing process, text block describing what's shown. Image right, content left.
- **Category routing.** Image of category hero product, content with a heading and button routing to the collection page.

## Notes

Stack two image-with-text sections alternating image left and image right for a rhythmic editorial homepage section.
