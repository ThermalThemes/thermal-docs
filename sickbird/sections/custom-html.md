# Custom Liquid

A raw Liquid/HTML embed. The escape hatch for third-party widgets, embed codes, and markup the section library doesn't cover.

## Section settings

- **Liquid / HTML** — The code field. Full Liquid is available, including theme and store objects.
- **Padding top / bottom** — Default 0 so embeds control their own spacing.
- **Color scheme**.

## Notes

- Prefer a real section or theme block when one covers the need — custom code doesn't inherit future theme improvements.
- Scripts in this section run on the storefront; only paste embed code from providers you trust.
