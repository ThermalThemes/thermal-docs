# Quick order list

A quantity-entry order form listing a collection's products and variants, for buyers who order many line items at once — wholesale accounts, team orders, restocks.

## Section settings

- **Collection** — The collection to list.
- **Show product image / SKU / price / availability / vendor** — Image, SKU, price, and availability default on.
- **Enable product search** — Default on; filters the list as the buyer types.
- **Enable filtering** — Default off.
- **Padding top / bottom**, **Color scheme**.

## Blocks

Takes [theme blocks](./index#theme-blocks) for a header above the list.

## Notes

- Put this on a dedicated page template linked from a "Wholesale" nav item rather than mixing it into retail pages.
- Quantity changes add to the same cart as the rest of the storefront — no separate checkout.
