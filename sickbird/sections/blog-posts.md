# Blog posts

A grid of article cards pulled from a chosen blog. Brings editorial content onto the homepage or any landing page.

## Section settings

- **Blog** — The blog to pull from.
- **Posts to show** — 2–12, default 3. **Columns on desktop** — 1–4, default 3.
- **Show featured image** — Default on, with **Image aspect ratio** (`adapt`, `square`, `portrait`, `landscape`).
- **Show date** — Default on. **Show author** — Default off. **Show excerpt** — Default on.
- **Show "View all" link to the blog** — Default off, as `link` or `button`.
- **Exclude current article** — On article templates, suppresses the article being viewed so it doesn't appear in its own related-articles feed. No effect elsewhere.
- **Enable carousel on mobile** — Default on.
- **Padding top / bottom**, **Color scheme**.

## Blocks

Takes [theme blocks](./index#theme-blocks) for the header area.

## Example use cases

- **The journal teaser.** Three landscape cards with date and excerpt on, under a display heading, with view-all linking to the blog.
- **Related reading.** On the article template with **Exclude current article** on.

## Notes

- Cards use each article's featured image; set one on every article or the grid renders unevenly.
