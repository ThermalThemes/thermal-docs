# Rich text

Block-composed text content in a column — the manifesto, the brand statement, the long answer. Width runs from a narrow reading column to a true full-bleed.

## Section settings

- **Content width** — `small`, `medium`, `large`, `full` (page width), `edge` (viewport full-bleed — pair with a display-size heading for a full-bleed type statement).
- **Content alignment** — `left`, `center`, `right`.
- **Show brand mark watermark** — A faint oversized theme mark pinned right of the content. Decorative; default off.
- **Padding top / bottom**, **Color scheme**.

## Blocks

Takes [theme blocks](./index#theme-blocks) — Heading (with display size and highlight effect), Subheading, Text, Button, Caption, Divider, Spacer.

## Example use cases

- **The manifesto slab.** `width: edge` on the ink scheme, heading at display `xl`, watermark on — a full-bleed statement between commerce sections.
- **Reading column.** `width: small`, left-aligned, for policy or story copy.

## Notes

- The heading block's highlight effect (accent or outline on one phrase) is the cheap way to make a statement heading graphic without an image.
