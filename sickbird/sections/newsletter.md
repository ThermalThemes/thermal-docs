# Newsletter

An email-capture form. Submissions create customers in your Shopify admin with the email-marketing opt-in set.

## Section settings

- **Content width** — `small`, `medium`, `large`.
- **Content alignment** — `left` or `center`.
- **Layout** — `stacked`, or `split` (header left, form right at desktop, stacking on mobile).
- **Show first name / last name / phone fields** — All off by default; email-only converts best.
- **Success message** — Default "Thanks for subscribing!".
- **Padding top / bottom**, **Color scheme**.

## Blocks

Takes [theme blocks](./index#theme-blocks) — typically Subheading, Heading, Text above the form.

## Example use cases

- **The dark closing slab.** Split layout on the ink scheme just above the footer — heading left, form right. The demo's "forecast list" signup.

## Notes

- There's also a newsletter block inside the [Footer](./footer) for a quieter persistent placement; use one or the other per page, not both.
