# Translations and languages

## Languages included

The words that belong to the theme (button labels such as Add to cart, form labels, messages such as Sold out) are included in:

- English
- German
- Spanish
- French
- Italian

If your store is in one of these languages, the theme's wording appears in it automatically.

## Changing the theme's wording

To change any wording that comes from the theme:

1. Go to **Online Store > Themes**.
2. Click the menu beside Plinth and choose **Edit default theme content**.
3. Search for the wording you want to change, edit it and save.

This is how you would change, for example, the text of the Add to cart button.

## Adding another language

1. In the Shopify admin, go to **Settings > Languages** and add the language.
2. Install Shopify's **Translate & Adapt** app (or another translation app) to translate your products, collections, pages and the text you typed into the theme editor.
3. For a language the theme does not include, translate the theme's wording in the same app, or in **Edit default theme content** after switching the language at the top of that page.

Your own content, including section headings, Hero headlines and button labels you typed into the theme editor, is translated through the translation app, not in the theme.

## Right-to-left languages

Plinth supports right-to-left languages such as Arabic and Hebrew. The layout mirrors automatically when a customer views the store in one of them. Options named **Start** and **End** follow the reading direction: Start is the left in English and the right in Arabic.

## Country and language selectors

Customers can change country (and so currency) and language from the header and from the sign-off.

- In the **Header** section, **Country and language selectors** can be **Country and language**, **Country only**, **Language only** or **None**.
- In the **Sign-off** section, set **Detail** to **Complete** to show the selectors there too.

Each selector shows only when the store sells in more than one country or language. If you have one market and one language, nothing appears.

## Currency codes

**Theme settings > Currency > Show currency codes** adds the currency code to prices, as in $48.00 USD. Turn it on if you sell in currencies that share a symbol.

## A few phrases with built-in translations

Some optional labels fall back to translated wording when you leave them empty. For example, the **Label** of the Press row reads "As seen in", translated for each language, until you type your own.
