# Presets

Plinth comes with three presets. A preset is a starting point: a set of colours, fonts, spacing and a home page arrangement. Every preset uses the same sections and the same settings, so anything one preset does you can do in another.

## What each preset sets

| | Plinth | Lowfold | Ironwell |
| --- | --- | --- | --- |
| **Ground** | Split | Dark | Light |
| **Type pairing** | Serif | Grotesk | Sans |
| **Heading font** | Source Serif 4, regular | Geist, bold | Geist, semibold |
| **Body font** | Geist | Source Serif 4 | Geist |
| **Accent font** | IBM Plex Mono | IBM Plex Mono | IBM Plex Mono |
| **Section spacing** | Generous | Standard | Compact |
| **Default color scheme** | Scheme 1 (warm off-white) | Scheme 3 (near-black) | Scheme 6 (white) |
| **Overlay color scheme** | Scheme 3 | Scheme 3 | Scheme 6 |
| **Accent colour** | Warm rust | Teal | Blue |
| **Page width** | Spacious | Spacious | Spacious |
| **Shelf rule** | Hairline | Hairline | Hairline |
| **Label style** | Mono capitals | Mono capitals | Mono capitals |

### Plinth

Light pages with dark moments. The opening section, the figures and the sign-off sit on a near-black ground; everything else is on warm off-white. A serif headline over a clean sans body. The most open spacing of the three.

Home page: Hero, Statement, Product rail, Collection mosaic, Numbers, Annotated product, Up close, Tabbed collections, Journal.

### Lowfold

Dark throughout, with a teal accent and a bold sans headline. Standard spacing.

Home page: Hero, Statement, Numbers, Product rail, Collection list, Annotated product, Before and after, Tabbed collections, Up close, Press row, Journal.

### Ironwell

White throughout, with a blue accent and a semibold sans headline. The tightest spacing, which suits larger catalogues.

Home page: Hero, Product rail, Statement, Numbers, Collection mosaic, Annotated product, Icon list, Tabbed collections, Up close, Press row, Accordion, Journal.

## How to switch presets

There are two ways.

**Add the other preset as a new theme.** In the Shopify Theme Store, open Plinth, choose the preset you want and add it to your library. This gives you that preset's settings and home page arrangement. Content you added to your current copy of the theme (text, images, chosen collections) is not carried across, so this is best done early.

**Change the settings yourself.** You keep all your content. In **Theme settings**:

1. Under **Ground and type**, set **Ground** and **Type pairing** to the values in the table above.
2. Under **Typography**, pick the matching **Heading font** and **Body font**.
3. Under **Layout**, set **Section spacing**.
4. Under **Colors**, set **Default color scheme** and **Overlay color scheme**.

The accent colour is part of the colour schemes. To change it, see [Colour and grounds](../customizing/colour#changing-the-accent).

## Mixing presets

The settings are independent. A Dark ground with the Serif type pairing, or a Light ground with Generous spacing, both work. The one pairing to keep is **Ground** with **Default color scheme**: with **Dark**, set the default scheme to Scheme 3; with **Light**, set it to Scheme 6.
