# Presets

Mammoth comes with one preset, also called **Mammoth**. A preset is a starting point: a set of colours, fonts, spacing and a home page arrangement. It is the look of the Stillroom demo store. Every value it sets is an ordinary theme setting, so you can change any of them.

## What the preset sets

| | Mammoth |
| --- | --- |
| **Ground** | Split |
| **Type pairing** | Serif |
| **Heading font** | Source Serif 4, regular |
| **Body font** | Geist |
| **Accent font** | IBM Plex Mono |
| **Section spacing** | Generous |
| **Default color scheme** | Scheme 1 (warm off-white) |
| **Overlay color scheme** | Scheme 3 |
| **Accent colour** | Warm rust |
| **Page width** | Spacious |
| **Shelf rule** | Hairline |
| **Label style** | Mono capitals |

### Mammoth

Light pages with dark moments. The opening section, the figures and the sign-off sit on a near-black ground; everything else is on warm off-white. A serif headline over a clean sans body.

Home page: Hero, Statement, Product rail, Collection mosaic, Numbers, Annotated product, Ticker, Shop the set, Up close, Pull quote, Media with text, Tabbed collections, Journal.

## Changing the look

Everything the preset sets is a theme setting, so you keep all your content when you change it. In **Theme settings**:

1. Under **Ground and type**, set **Ground** (Split, Dark or Light) and **Type pairing** (Serif, Grotesk or Sans).
2. Under **Typography**, pick the **Heading font** and **Body font**.
3. Under **Layout**, set **Section spacing** (Generous, Standard or Compact).
4. Under **Colors**, set **Default color scheme** and **Overlay color scheme**.

The accent colour is part of the colour schemes. To change it, see [Colour and grounds](../customizing/colour#changing-the-accent).

## Mixing settings

The settings are independent. A Dark ground with the Serif type pairing, or a Light ground with Generous spacing, both work. The one pairing to keep is **Ground** with **Default color scheme**: with **Dark**, set the default scheme to Scheme 3; with **Light**, set it to Scheme 6.
