# Collection list

A grid of collection tiles linking to collection pages. The front-door section for routing visitors to disciplines or categories.

## Section settings

- **Subheading / Heading** — Section header, with **Heading display size** (`none`–`xl`).
- **Columns on desktop** — 2–6, default 3. **Columns on mobile** — 1 or 2.
- **Image aspect ratio** — `adapt`, `square`, `portrait`, `landscape`.
- **Text alignment** — `left` or `center`.
- **Enable carousel on mobile** — Default on.
- **Padding top / bottom**, **Color scheme**.

## Blocks

- **Collection** — A collection picker plus an optional **Custom label** that overrides the collection title on the tile.

## Example use cases

- **Discipline front doors.** Three portrait tiles — snow, skate, surf — with custom labels in the display register, right under the hero.

## Notes

- Tiles use the collection's featured image; set one on each collection in the admin or the tile falls back to the first product image.
- Custom labels let tile copy diverge from admin collection titles ("THE WHITEOUT" over a collection named "Snow").
