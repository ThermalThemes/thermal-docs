# Dynamic grid

A flexible grid that lays out theme blocks into a configurable number of columns. Use it when you want a freeform mosaic of headings, images, buttons, and rich text rather than a purpose-built section.

## What it does

Arranges its theme blocks into a grid with independent desktop and mobile column counts and a chosen gap. Because it accepts the shared [theme block library](./#theme-blocks), each cell can be a heading, image, button, divider, spacer, or any other supported block — reordered per instance.

## Section settings

- **Columns (desktop)** — number of columns on desktop.
- **Columns (mobile)** — number of columns on mobile.
- **Gap** — `none`, `small`, `medium`, `large`.
- **Padding top / bottom** — 0–160px.
- **Color scheme** — Section-level scheme.

## Blocks

Accepts the shared **theme block library** — heading, subheading, text, caption, button, image, video, rich text, details, divider, spacer, custom Liquid. See [Theme blocks](./#theme-blocks).

## Example use cases

- An editorial mosaic of mixed type and imagery.
- A compact feature or benefit grid built from heading + text blocks.
- A bespoke layout that no single purpose-built section covers.
