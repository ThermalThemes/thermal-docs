# Multirow

A stack of full-width rows, each pairing an image with text. Used for process stories, founder notes, and sequential narrative where every beat wants its own band across the page.

## What it does

Renders one row per block, alternating (or fixing) the image to the left or right. Each row carries its own image, label, heading, body, and a single button. Rows share the section's color scheme and image aspect ratio for a consistent rhythm down the page.

## Section settings

- **Image position** — `left`, `right`, `alternating`. Alternating flips the image side row to row.
- **Image aspect ratio** — `adapt`, `square`, `portrait`, `landscape`.
- **Padding top / bottom** — 0–160px.
- **Color scheme** — Section-level scheme.

## Blocks

One block type: **Row**.

- **Image** — the row's image.
- **Subheading** — monospace label above the heading.
- **Heading** and **Text**.
- **Button label / link** — a single button per row.

## Example use cases

- A multi-step process or "how it's made" story, one beat per row.
- A founder or brand note paired with a portrait.
- A sequence of feature bands on a long-form landing page.
