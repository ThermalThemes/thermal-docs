# Testimonials

Customer or reviewer quotes with attribution. Ratings render in the theme's mark — not generic stars.

## Section settings

- **Subheading / Heading** — Section header.
- **Columns on desktop** — 1–4, default 3. **Columns on mobile** — 1 or 2.
- **Enable carousel on desktop** — Default off. **Enable carousel on mobile** — Default on.
- **Show quotation marks** — Default on.
- **Padding top / bottom**, **Color scheme**.

## Blocks

- **Testimonial** — **Star rating** (0–5; 0 hides the rating), quote, **Name**, **Title or publication** ("Verified buyer", or a publication and date), avatar image, optional link.

## Notes

- The attribution role field carries the range: customer reviews and press pull-quotes are the same block with different attribution.
- One or two columns with longer quotes reads editorial; three or four short ones reads like social proof volume. Pick one mode per page.
