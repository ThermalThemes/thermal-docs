# Accordion

Collapsible question-and-answer items. The FAQ section, and the home for shipping, returns, and care content on any page.

## Section settings

- **Content width** — `small`, `medium`, `large`.
- **Open first item by default** — Default off.
- **Padding top / bottom**, **Color scheme**.

## Blocks

- **Heading** — Section heading above the list, with size and alignment.
- **Subheading** — Optional label above the heading.
- **Item** — One collapsible row: heading (the question) plus rich-text content (the answer).

## Notes

- Items are individually focusable and keyboard-operable.
- For a single collapsible row inside another section (shipping notes in a product info column), use the Details theme block instead of this section.
