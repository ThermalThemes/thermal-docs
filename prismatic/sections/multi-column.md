# Multi-column

Repeating column blocks, each with an image, heading, and text. Carries benefit rows, feature summaries, and trust content without a dedicated section per use.

## Section settings

- **Subheading / Heading** — Section header, with **Heading display size** (`none`–`xl`).
- **Columns on desktop** — 1–6, default 3. **Columns on mobile** — 1 or 2.
- **Column content alignment** — `left` or `center`.
- **Enable carousel on mobile** — Default on.
- **Padding top / bottom**, **Color scheme**.

## Blocks

- **Column** — Image, heading, rich-text description, optional link + link label.

## Example use cases

- **The guarantees row.** Three left-aligned columns — pressed by hand, numbered runs, ships flat — on the paper scheme between two graphic slabs.
- **Discipline intro.** Columns per discipline with photography, each linking to its collection.

## Notes

- Left alignment matches the theme's register; center reads more conventional.
- This section covers trust-badge use cases; there is no separate trust-icons section in the library.
