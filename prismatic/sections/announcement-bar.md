# Announcement bar

A slim promotional strip that sits above the header in the header group. Carries one or more short announcements; multiple announcements can rotate automatically.

## Settings

- **Auto-rotate announcements** — Default off. When on, announcements cycle.
- **Rotation interval** — 3–10 seconds, default 5. Visible only when auto-rotate is on.
- **Padding top / bottom** — 0–20px ranges, default 8.
- **Color scheme** — The demo runs the bar on the orange scheme as the page's single accent moment.

## Blocks

- **Announcement** — Rich text plus an optional link that wraps the whole announcement.

## Notes

- Keep each announcement to one line. The bar truncates gracefully but reads best short: a shipping cutoff, a restock date, a flat statement.
- If you run the announcement bar on the orange scheme, avoid a second orange section on the same page — the accent works by being singular.
