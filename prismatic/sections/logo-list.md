# Logo list

A horizontal strip of logos — press, stockists, partners, certifications.

## Section settings

- **Subheading / Heading** — Default heading "As seen in".
- **Logo height** — `small`, `medium`, `large`.
- **Display logos in grayscale** — Default on; keeps mismatched brand colors from fighting the palette.
- **Enable carousel on desktop** — Default off. **Enable carousel on mobile** — Default on.
- **Padding top / bottom**, **Color scheme**.

## Blocks

- **Logo** — Logo image plus an optional link.

## Notes

- Upload logos with transparent backgrounds at consistent heights; the section normalizes height but not visual weight.
- For logos with quotes attached, use [Press](./press) instead.
